# TypeSekai Mapper for Mudlet

The whole TypeSekai MUD map for Mudlet, and a script that keeps the map centred on you as you walk (the server tells Mudlet where you are over GMCP).

Install it in Mudlet by typing:

    lua installPackage("https://raw.githubusercontent.com/Xenochi-vibe/typesekai-mudlet/main/TypeSekai-Mapper.mpackage")

or download `TypeSekai-Mapper.mpackage` and install it from Mudlet's Package Manager. Type `tsmap` in Mudlet for its commands, and `help mudlet` in the game.
